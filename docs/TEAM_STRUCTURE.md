## 1. Overview

### 1.1 Purpose

This document defines the team structure, roles, and staffing plan for Plunderstorm Mobile across all development phases. It serves as the foundation for hiring decisions, resource allocation, and organizational planning.

### 1.2 Project Staffing Philosophy

| Principle | Description |
|-----------|-------------|
| **Lean Core** | Small full-time team with outsourcing for specialized work |
| **T-Shaped Skills** | Team members with depth in one area, breadth across others |
| **Scalable** | Structure that can grow without major reorganization |
| **Autonomous** | Teams empowered to make decisions within their domain |
| **Remote-First** | Support distributed team from day one |

### 1.3 Team Size Targets

| Phase | Duration | Team Size | Notes |
|-------|----------|-----------|-------|
| Pre-Production | 2-3 months | 2-4 | Core concept, prototyping |
| Alpha | 3-4 months | 4-8 | Core development |
| Beta/Soft Launch | 3-4 months | 6-12 | Polish, content |
| Global Launch | 1-2 months | 8-12 | All hands on deck |
| Live Operations | Ongoing | 4-10 | Sustainable operations |
